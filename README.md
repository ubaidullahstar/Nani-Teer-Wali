## 📁 GitHub Custom Folders Guide (Apni Marzi Se Changes Karein)

Aap GitHub par direct in folders mein files replace kar ke apni marzi ki photos aur audios add kar sakte hain:

### 1. 🖼️ `background_image/` (Game Background)
- **Path:** `/background_image/`
- **File:** `background.jpg`
- **Kaam:** Yahan aap jo bhi image dalenge, wo poori game ke background mein aa jayegi (Normal Mode, Maze Mode, aur Mode Select screen par).

### 2. 🎵 `audio/` (Custom Audio & Music)
- **Path:** `/audio/`
- **Files:**
  - `app_start.mp3` - Jab game open ho tab bajne wali audio.
  - `winning.mp3` - Jab aap level win/complete karein tab bajne wali audio.
  - `wrong_move.mp3` - Jab aap ghalat move choose karein ya blocked teer par tap karein tab bajne wali audio.
- Supported formats: `.mp3`, `.wav`, `.ogg`

### 3. 👤 `app_picture/` (Character Photo / App Avatar)
- **Path:** `/app_picture/`
- **Files:** `app_picture.png` ya `app_picture.jpg`
- **Kaam:** Yahan aap apni photo ya character ki photo daal sakte hain jo game ke logo, avatars aur victory screens par show hoti hai.

---

## 🎮 Game Features
- **Mode Select:** Normal Mode (Grid Arrow Escape) ya Maze Mode (Snake Labyrinth)
- **10-10 Levels:** Dono games mein 10 levels, har level ke sath maze aur bhi zyada complex!
- **Sound & Haptics:** Full audio support with settings toggle.
