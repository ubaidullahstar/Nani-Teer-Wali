# 👤 App Character Picture (Nani / Logo Picture)

Yahan aap app ki apni photo (character avatar / logo) change kar sakte hain!

### Files:
- **`app_picture.png`** ya **`app_picture.jpg`**:
  - Ye photo app ke main header badge, Mode Select screen, aur level completion dialogs mein show hoti hai.

### Kaise change karein (How to customize on GitHub):
1. Is folder (`app_picture/`) mein apni marzi ki photo upload karein aur uska naam `app_picture.png` ya `app_picture.jpg` rakhein.
2. Supported formats: **.png**, **.jpg**, **.jpeg**, **.webp**
3. Recommended: Square picture (1:1 aspect ratio) taake circular frame mein bilkul perfect fit ho.
