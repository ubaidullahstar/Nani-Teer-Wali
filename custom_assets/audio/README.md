# 🎵 Custom Audio (Sound Effects & Music)

Yahan aap apni marzi ke audio sounds add ya replace kar sakte hain!

### Available Audio Files:
1. **`app_start.mp3`** (ya `app_start.wav`):
   - Jab app open/start ho tab ye audio baje ga.
2. **`winning.mp3`** (ya `winning.wav`):
   - Jab aap koi level jeetenge (Normal Mode ya Maze Mode), tab ye winning sound baje ga.
3. **`wrong_move.mp3`** (ya `wrong_move.wav`):
   - Jab aap ghalat move choose karein ge ya blocked teer/arrow par tap karein ge, tab ye audio baje ga.

### Kaise change karein (How to customize on GitHub):
- GitHub par is folder (`audio/`) mein ja kar apna `.mp3` ya `.wav` file upload karein aur upar diye gaye naamon (`app_start.mp3`, `winning.mp3`, `wrong_move.mp3`) se save karein.
- Supported audio formats: **.mp3**, **.wav**, **.ogg**, **.m4a**
