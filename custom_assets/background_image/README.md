# 🖼️ Background Image (Game Background)

Yahan aap apni marzi ki background image daal sakte hain!

### Kaise change karein (How to customize on GitHub):
1. Is folder (`background_image/`) mein apni photo upload karein ya existing `background.jpg` ko replace karein.
2. Supported formats: **.jpg**, **.jpeg**, **.png**, **.webp**
3. Recommended resolution: **1080x1920** ya vertical phone wallpaper.
4. Game khud ba khud is image ko background mein set kar degi aur readibility ke liye smooth contrast gradient overlay apply karegi.
